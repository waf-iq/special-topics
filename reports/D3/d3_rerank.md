# D3 Task 2 — Reranker comparison (SciFact 60-query holdout)

Generated by `scripts/eval_rerank.py`. 60 SciFact holdout queries over 5663 SciFact chunks. Candidate pool from the blessed D2 retriever (`metric=l2`, `hybrid_weight=0.777`, `candidate_k=27`); each reranker reorders the pool down to top-5. `p95_latency_ms` is end-to-end (retrieval + rerank), so the `none` row is pure retrieval and the extra latency elsewhere is the rerank cost.

## Observations (from this run)

- **Both cross-encoders beat no-rerank** on NDCG@5 *and* Recall@5. `bge` is strongest
  (+7.5pp at pool 30, +9.3pp at pool 20); `minilm` is a lighter +4.0–4.7pp.
- **Pool = 20 is the sweet spot for both cross-encoders** — `bge` peaks at pool 20
  (NDCG@5 = 0.6537, Recall@5 = 0.7433) and `minilm` at pool 20 (0.6082). Going deeper
  (30/50) *lowers* quality slightly **and** costs more latency — diminishing/negative returns,
  because a bigger pool feeds the reranker more distractors.
- **MMR regresses (−8.4pp).** Its diversity term penalizes near-duplicate relevant chunks,
  which is the wrong objective for SciFact claims that usually have a single relevant chunk.
  Not a viable candidate here.
- **Latency cost (end-to-end p95):** none ≈ 72 ms → `minilm`@20 ≈ 332 ms (~4.6×) →
  `bge`@20 ≈ 1145 ms (~16×). The cross-encoder runs one transformer pass per candidate, so
  latency scales with pool size (visible in the sweep).

**Decision framing (for us to pick together):**
- **Best quality:** `bge` @ pool 20 — +9.3pp NDCG@5, but ~1.1 s p95.
- **Best quality-per-millisecond:** `minilm` @ pool 20 — +4.7pp NDCG@5 at ~0.33 s p95.
- The call is how much latency `/ask` can spend for the extra ~4.6pp that `bge` buys over `minilm`.

## Reading the results / how to pick a winner

- **Quality:** highest `ndcg@5` (and its `lift` over `none`).
- **Latency:** `p95_latency_ms` — the cross-encoders add a transformer pass per candidate, so they cost more than `none`/`mmr`.
- **Trade-off:** prefer the backend with the best lift-per-millisecond unless a higher-latency backend clears a quality bar we care about.
- Note: SciFact claims usually have a single relevant chunk, so `mmr`'s diversity term has little to reward and may not beat a pure cross-encoder here.

**Winner: `bge` (BAAI/bge-reranker-base) at pool 20 — chosen for now.** Best NDCG@5
(0.6537, +9.3pp over no-rerank) at the cost of ~1.1 s p95. Set as `_BLESSED_RERANKER = "bge"`
in `src/csai415/rerank.py`; integrator keeps executor `candidate_k=20` (see note in
`briefs/D3_D4_TASKS.md`, Task 7). If `/ask` latency becomes a concern, `minilm` (+4.7pp at
~0.33 s) is a one-line fallback.
